# Cool Recipe Guide

## Recipes

- Tasty Lasagna (featured recipe)
- Cinnamon Rolls
- Mac and Cheese
- Rich Chocolate Cake
- Chicken Noodle Soup
- Apple Pie

## Features

- Home page with recipe cards laid out using flexbox
- A page for each recipe with an image, ingredients list, and steps
- Navigation bar on every page that highlights the page you're on
- Random Recipe button (picks a random recipe that isn't the one you're already on)
- Custom background patterns for each page (stripes, dots, circles, etc)
- Footer on every page

## Built with

- HTML
- CSS
- A little JavaScript (for the random recipe button)

## What I learned

- Basic html structure and common tags (lists, links, images, tables)
- How to link between pages within the site with relative paths (so the site works no matter where it's hosted)
- How specificity works in css (ids beat classes which beat type selectors)
- Combinators for targeting specific elements (for example ".navbar li a {...}")
- Border box reset (padding and border are included in the width/height so elements don't grow when you change them)
- How margin collapses + inline vs block elements
- How to use flexbox (I learned it by playing Flexbox Froggy and then used it for the home page and navbar)
- How to make background patterns with repeating-linear-gradient and radial-gradient
- The !important keyword (used it to make the text white on the cake page since the background is dark)

## Running it

Just open index.html in your browser or go to https://coolrecipeguide.netlify.app
